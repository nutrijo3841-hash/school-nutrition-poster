# 🍎 영양쏙쏙 (Nutri-Poster)
> **전국 유·초·중·고등학교 영양교사를 위한 만능 식재료 교육 포스터 웹앱**

영양교사 선생님들이 매월·매주 식생활 교육 자료와 급식 게시판 포스터를 만드느라 겪으시는 디자인 및 자료 조사 부담을 덜어드리기 위해 개발된 맞춤형 교육 웹앱입니다.

식재료 이름 하나만 검색하면, **국가표준식품성분표 기반 영양 정보**, **교육부 지정 19종 급식 알레르기 번호**, **학교급별(유·초등 vs 중·고등) 눈높이 스토리텔링**, **사계절 제철 달력**이 반영된 완성도 높은 포스터가 1초 만에 자동으로 만들어집니다.

---

## 🌟 핵심 기능

### 1. 템플릿 기반 원클릭 즉시 자동 완성
- 식재료 이름 검색 또는 목록 클릭 즉시 디자인 템플릿에 교육 텍스트와 비주얼이 자동 배치됩니다.
- 학교 다빈도 식재료(시금치, 토마토, 고등어, 연근, 감자, 당근, 닭고기, 쇠고기, 미역, 귤 등)가 기본 내장되어 있습니다.

### 2. 멀티 폼팩터 자유 전환
- 📄 **A4 / A3 세로형 포스터**: 급식실 배식대, 복도 영양게시판, 식당 벽 부착용 (A4 1장 출력 최적화)
- 📺 **16:9 와이드 모니터 슬라이드**: 급식실 천장 TV, DID 전자게시판 송출용
- 📱 **1:1 카드뉴스**: 학교 홈페이지, e-알리미, 아이엠스쿨, 가정통신문, SNS 첨부용

### 3. 학교급별(유초등 vs 중고등) 맞춤 모드
- 🐥 **유치원·초등학교 모드**:
  - 친근하고 귀여운 동화형 어투 ("뽀빠이도 반한 초록 영양 대장!", "키 쑥쑥 뼈 튼튼!")
  - 오감 탐구 이야기와 신기한 식재료 비밀
- 🎓 **중학교·고등학교 모드**:
  - 수험생 피로 해소, 뇌 기능 활성화, 학업 스트레스 완화 영양학 인포그래픽
  - 기능성 성분(루테인, 안토시아닌, 라이코펜 등)의 체내 작용 원리 설명

### 4. 학교급식 필수 법정 규격 준수
- **식약처·교육부 지정 19종 급식 알레르기 유발물질 공식 번호 자동 표기**:
  - `⚠️ [알레르기 12번] 토마토 함유 - 해당 알레르기 학생은 섭취 전 영양교사와 상담하세요`
  - 알레르기 유발물질이 아닌 경우 `✅ 안심 식재료: 19종 알레르기 해당 없음` 배지 표기
- **12개월 제철 캘린더 인디케이터**: 제철인 월을 시각적으로 하이라이트

### 5. 선생님을 위한 자유 편집 (Click to Edit)
- 포스터 안의 **학교명**, **제목**, **부제목**, **영양 꿀팁**을 마우스로 클릭하면 원하는 문구로 직접 수정할 수 있습니다.
- "서울○○초등학교 급식실", "○○중학교 영양상담실" 등 학교 상황에 맞게 1초 만에 맞춤 변경 가능!

### 6. 다채로운 비타민 테마 컬러
- 🌿 싱그런 파스텔 그린
- 🍊 활력 비타민 오렌지
- 🫐 슈퍼푸드 퍼플
- 📘 스마트 클래스룸 블루
- 🌸 러블리 파스텔 핑크

### 7. Google Gemini AI 확장 분석
- 기본 등록되지 않은 새로운 식재료(예: *샤인머스캣, 콜라비, 바질, 아스파라거스, 로메인* 등)도 검색창에서 **[AI 분석]** 버튼을 누르면 인공지능이 영양 성분과 학교급별 포스터를 실시간으로 자동 생성합니다.
- API 키가 없어도 내장된 지능형 규칙 엔진으로 100% 정상 작동합니다.

### 8. 편리한 내보내기 & 인쇄
- 🖼️ **고화질 PNG 이미지 저장**: 2배율(2x) 선명한 고해상도 인쇄 품질로 다운로드
- 🖨️ **급식실 즉시 인쇄**: A4 1페이지에 딱 맞게 여백 자동 세팅
- 📋 **클립보드 복사**: 한글 문서(HWP), 파워포인트(PPT)에 바로 붙여넣기(`Ctrl+V`) 가능

## 🚀 실행 방법

### 방법 1: 가장 간편한 방법 (무설치 / 더블클릭)
1. `index.html` 파일을 더블 클릭하여 크롬, 엣지, 웨일 등 웹 브라우저에서 바로 엽니다.
2. 행정망/교육망 망분리 PC나 USB에서도 인터넷 브라우저만 있으면 별도 설치 없이 즉시 실행됩니다.

### 방법 2: 로컬 서버 실행
1. `run_app.bat` 파일을 더블 클릭합니다.
2. 자동으로 브라우저(`http://localhost:8080`)가 실행됩니다.
